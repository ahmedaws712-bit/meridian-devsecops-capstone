# Security RACI

## Objective

This RACI defines ownership for security controls across the Meridian DevSecOps capstone.

| Activity | Developer | Cloud Engineer | Security Engineer | Reviewer / Approver |
|---|---|---|---|---|
| Application code changes | Responsible | Consulted | Consulted | Accountable |
| Pull request review | Responsible | Consulted | Consulted | Accountable |
| Branch protection configuration | Consulted | Responsible | Consulted | Accountable |
| Terraform security controls | Consulted | Responsible | Consulted | Accountable |
| IaC scan remediation | Consulted | Responsible | Consulted | Accountable |
| OPA policy updates | Consulted | Consulted | Responsible | Accountable |
| Secrets scanning | Responsible | Consulted | Responsible | Accountable |
| SAST findings | Responsible | Consulted | Responsible | Accountable |
| Container image scanning | Responsible | Consulted | Responsible | Accountable |
| SBOM generation | Responsible | Consulted | Responsible | Accountable |
| Kubernetes manifest hardening | Consulted | Responsible | Responsible | Accountable |
| Falco runtime detection | Consulted | Responsible | Responsible | Accountable |
| Compliance evidence pack | Consulted | Consulted | Responsible | Accountable |
| Incident response playbooks | Consulted | Responsible | Responsible | Accountable |
